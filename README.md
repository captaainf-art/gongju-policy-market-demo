# 공주시 고마정책마켓 — 시연 프로토타입

V0.6 · 구축 검토용 인터랙티브 시연본. TeamBridge와 별도로 관리합니다.

## 시연 범위
정책 검색·필터·저장·비교, 내 생활정보, 모의 신청, 지원 이력 샘플, 관심 모집 알림.

실제 행정서비스가 아니며 정책·금액·일정·지급 내역은 예시입니다. 실제 개인정보를 입력하지 마세요. 입력값은 각 브라우저의 localStorage에만 보관됩니다. 실제 인증·지급·신청 전송·문자 발송은 수행하지 않습니다.

## 실행
GitHub Pages 또는 로컬 정적 서버에서 index.html을 여세요. 사진은 공주시 행복누림 원격 URL을 참조하므로 인터넷 연결이 필요합니다. 해당 이미지의 재사용 허가를 보증하지 않습니다.

## 자산
공주시 심볼은 제공된 브랜드 가이드 원본을 사용하며 색상·형태를 재작성하지 않았습니다. 나머지 아이콘은 SVG입니다. 기관 운영 공식 사이트가 아닌 서비스 제안용 시연입니다.
